# Environment art review drafts

`overgrown_ruins_environment_v1.png` is a concept sheet for six Overgrown Ruins
world tiles: quiet floor, cracked floor, shallow water, solid wall, broken wall,
and sparse moss decoration (left to right, top row then bottom row). It is not
referenced by the game manifest and does not change gameplay visuals.

Generated with the built-in image generation tool using a four-color, sparse
top-down pixel-art prompt. This 1536×1024 review image is not yet a pixel-exact
32×32 gameplay atlas. Approval of the visual direction should precede any
cropping, pixel normalization, publishing, or work on other biome sheets.

Prompt: “Create one clean top-down roguelike Overgrown Ruins sprite-sheet concept
with exactly six square tile designs in a three-column, two-row grid: quiet
walkable floor, lightly cracked floor, shallow water, solid wall, broken wall,
and sparse moss. Use hard-edged, chunky, old-school pixel art and only near-black
`#101b17`, dark green `#304c39`, moss `#789354`, and pale highlight `#d7dba2`.
Keep floors at least 75% quiet flat color; make walls clearly distinct. No
gradients, noise, antialiasing, characters, HUD, labels, or faux screenshots.”
