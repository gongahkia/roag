Urizen tilesets

2 images · vurmux · CC0-1.0 · Publisher and license

  • Main atlas: 2679x651 pixels. Publisher describes over 5500 12x12 tiles across multiple themes.
  • Main atlas uses a 13-pixel grid: 12x12 tiles, one-pixel gutters, one-pixel initial margin; 206 columns and 50 rows.
  • Four 12-pixel-wide magenta guide bands occupy zero-based tile columns 25, 51, 77, and 103; exclude these when choosing sprites.
  • Contains terrain, doors, walls, furniture, items, machinery, sci-fi equipment, characters, symbols, and bitmap lettering.
  • Free 2-bit sample: 261x92 pixels, on the same 12x12 / 13-pixel pitch layout; 20 columns and 7 rows.
  • Both are full-color RGBA PNG atlases. The 1-bit and 2-bit names describe the art style, not the PNG bit depth.
  • Strongest source for a future graphical Regolith map; the two-bit file is a limited showcase.
