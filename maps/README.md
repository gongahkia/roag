# Map examples

The six original `*-12345.dwmap.json` files retain v0.3 map schema1 and frontier-v1
recipes for comparisons/backward-compatibility tests. Do not replace them with
current output while keeping the same filename or expected hash.

The `living-*` examples are current schema2 templates containing exact cells,
biomes, ruins, encounters and crew counts. F3 opens these from the game; validation
and preview precede adoption. New colonies initialise health/knowledge and standard
supplies; these are not saved adventures with dead workers or armed explosives.
All worlds are finite and may be harsh or unrecoverable after poor decisions.
