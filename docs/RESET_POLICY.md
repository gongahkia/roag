# Reset policy

The pre-reset world, its characters, regions, routes, recipes, maps, presentation contracts, media, and Dullest Dungeon implementation were intentionally removed. Git history retains archaeology; the runtime tree does not retain compatibility adapters for that setting.

Draw and Dice were removed with the old concrete tavern content. Future games may add a generic activity through the same command/view/event boundary when they have a setting-neutral design and test fixture.

BigBlueTerm Nerd Font Mono, its licence, Pygame renderer infrastructure, app settings, and generic frontend chrome remain infrastructure rather than world content.
