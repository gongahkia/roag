# Vehicle content packs

`vehicle_text.json` contains player-facing wording for the stable vehicles defined mechanically in `vehicles.json`. Writing-focused authors may change vehicle and reserve names, domain labels, boarding, driving, service, interior, gangplank, and status narration using the declared templates.

Do not alter vehicle IDs, deck glyphs, regions, domains, capacity, condition, pace, harbour geometry, fixture positions, fuel rules, costs, terrain checks, action keys, save identities, or RNG. Those values remain engine-owned. Item, character, UI, vessel, travel, action, and ship-crisis wording remains in its existing presentation surface.
