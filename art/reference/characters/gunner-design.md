# Gunner reduction guide

This is a reduction brief for the non-runtime concept reference
`gunner-concept.png`. It is not source art and must never be cropped into a
runtime sprite.

- Retain: compact masked/helmeted head, blue shoulder/torso shape, close-held
  small ranged emitter, and one amber shoulder/energy-cell accent.
- Drop: hair strands, fabric tears, belts, realistic weapon detail, face
  detail, and every secondary pouch.
- Native 24 px silhouette: head 7–8 px wide, torso 10–12 px wide, narrow leg
  gap, one 3–4 px arm/device protrusion. Leave the forward edge quiet so the
  runtime weapon-direction indicator remains visible.
- Colour budget: charcoal contour, two gunmetal values, two blue values, one
  amber value, optional pale metal highlight.
- Read at 8× first, then at native 1× against dark forest and blue-grey reactor
  terrain. If a feature does not survive both, remove it.
