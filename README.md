# Roag

Roag is pivoting to a browser-based fantasy colony survival game with tower defense.
The selected stack is TypeScript, Phaser, and Vite. The colony must survive raids;
the run ends when its heart is destroyed or every colonist dies.

The web game has not been implemented yet. This checkout still contains the
existing C#/MonoGame game and its Lua/reference predecessors.
