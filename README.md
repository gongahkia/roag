# `Roag`

## Abstract

This is the final iteration of a small roguelike game I worked on over the span of 2 consecutive days in an effort to familiarise myself with OOP in Python.

## Usage 

To try it, download all the files within this folder, make sure they're in the same file directory, and run `input.py`. Make sure you have Python3 or later versions installed!
