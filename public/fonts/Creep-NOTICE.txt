Creep

This project bundles `Creep.ttf`, generated without glyph changes from the
upstream `creep.sfd` source in romeovs/creep at commit
d2a9ad0181f1f8fbeafa6a3a5959f631a3b69ebc.

Original project: https://github.com/romeovs/creep
Copyright (c) 2014 Romeo Van Snick
License: MIT; full text: Creep-LICENSE.txt

`Creep.ttf` is the upstream-compatible bitmap build. `Creep-outline.ttf` is a
local browser build that converts those same 16-pixel glyphs to square
TrueType outlines because Chromium Canvas 2D does not paint the bitmap-only
face. The glyph shapes are unchanged; the browser build has distinct metadata.
