# VIS-01 human visual review

Start an Expedition, then inspect the title, character select, a normal room,
an elite, a cache, a reward choice, and a boss. Also briefly open Sandbox to
ensure its supported compatibility path uses the same atlas rather than shapes.

Record concise notes for:

- floor and wall readability at chamber scale;
- the four player-class silhouettes;
- rusher/ranged/flanker/controller/heavy differentiation;
- hostile and player outline readability over source sprites;
- doors, cache/chest, hazards, projectiles, electric effects and boss clarity;
- bitmap-font legibility in HUD, XP/cash, reward choices and action receipts;
- whether any source cell looks like an accidental collage/screenshot crop.

Use `[READABLE]`, `[AMBIGUOUS]`, `[TOO BUSY]`, `[GOOD PIXELS]`, or
`[MAPPING BUG]` with the exact screen/semantic named. This tranche changes no
gameplay; report visual regressions separately from balance or encounter feel.
