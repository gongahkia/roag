# MOD-02 Expedition playtest

Play at least two fresh Expeditions with different characters. Do not inspect debug tools first. Record moments as `[BORING]`, `[WEAK]`, `[INTERESTING]`, `[POWERFUL]`, `[RIDICULOUS]`, `[BROKEN-GOOD]`, `[BROKEN-BAD]`, or `[ONE MORE RUN]`.

At roughly 2, 5, 10 and 15–20 minutes, ask: did the run already change, is there a build direction, did a surprising interaction appear, and does the late build feel substantially unlike the starting character?

Pay special attention to:

- whether one action ever starts a satisfying readable chain;
- whether labels explain why Arc/Force/fire/explosion/reload effects happened;
- whether repeated pickups make you want another stack;
- whether rewards are frequent without becoming annoying pauses;
- whether duplicates support a build while new items still appear;
- Projectile Storm, electric water fights, Kinetic Feedback against walls, component breaks, Reload Engine, and boss combat.

After each run, answer: “Did I want another run immediately? Which item made me want to find it again?”

Do not begin another implementation tranche from this document automatically. Human Expedition play decides the next direction.
