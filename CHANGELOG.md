# Changelog

## 0.4.0

- Added per-person duties, role pinning, exact AUTO-worker quotas, named job ownership
  and body-aware rally/hold/release commands, all tick-stamped and replayable.
- Added 3/6/9 crew choices for new frontier expeditions; compressed HUD supports all.
- Added karst, labyrinth, roots, chasms and crystal layouts, four biome keys and three
  profiles. Preserved previous layouts, legacy scenarios and frontier-v1 recipes.
- Added seeded multi-room ruins, finite caches, observation/survey/salvage/cull jobs,
  bounded wild growth and fauna, food-web interactions and disturbance-reactive sites.
- Added inert-to-armed demolition charges, fixed fuses, attenuated grid blasts, lethal
  damage, chain reactions and water-consuming ecology wards.
- Added map schema 2 with baked encounters and crew; schema 1 remains readable.
- Save envelope 0.4.0 prevents downgrades from silently loading unknown systems.
  Genuine 0.2 and 0.3 snapshots still advance to their original recorded state hashes.
- Added explicit tests for new systems, accounting, archive restrictions, GUI controls,
  longer-run replay and current-source benchmarks; retained original suites.
- Added repository handoff, agent guidance, system contracts and limitation records.

Inherited v0.3 change history is in docs/legacy-v030/CHANGELOG.md.
